# 04_quality_assessment — Study Quality Appraisal

**Status: derived from `06_included_studies/`.**

## Contents

- `quality_assessment.xlsx` — One row per included study, scoring
  methodological rigor/relevance against a fixed set of quality criteria.
  Used to weight or filter studies during synthesis (e.g., sensitivity
  analysis excluding low-quality studies).

## Rules

- Use the same `study_id` values as `06_included_studies/included_studies.csv`
  and `03_coding/coding_evidence.xlsx` so all artifacts join cleanly.
- Document the scoring rubric (criteria and scale) inside the workbook
  (see the `Rubric` sheet in `quality_assessment.xlsx`) rather than only in
  prose, so it travels with the data.
