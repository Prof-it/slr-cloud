# 05_synthesis — Aggregated Findings

**Status: derived from `03_coding/` and `04_quality_assessment/`.**

## Contents

- `comparative_coverage_matrix.xlsx` — Cross-tabulation of included studies
  against coding categories/themes, showing which studies address which
  governance aspects.
- `governance_gap_taxonomy.xlsx` — Structured taxonomy of governance gaps
  identified across the coded evidence, with supporting study references.
- `synthesis_notes.md` — Narrative synthesis notes, thematic analysis
  process, and inter-rater reliability statistics.

## Rules

- Every claim in `synthesis_notes.md` should be traceable to specific
  `evidence_id` values in `03_coding/coding_evidence.xlsx`.
- Do not introduce new codes or evidence at this stage — synthesis only
  aggregates/interprets what is already coded.
