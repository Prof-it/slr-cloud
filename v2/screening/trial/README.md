# Trial screening set (calibration only)

`trial_40.ris` / `trial_40.csv`: 40 records drawn from the archived **v1** EBSCO
export (`01_search/exports/search_results_by_database_2026-04.xlsx`, after the
v2 pipeline's dedup and rule filter; 636 records), seed 20261126:

- the 6 records of that export that reached v1 full-text review,
- 6 random records mentioning multi-cloud and a governance term (borderline cases),
- 28 random records from the rest,

in shuffled order. Used only to calibrate the screeners on the Task T1 criteria
(separate Rayyan review "TRIAL"). Trial decisions are not part of the v2
evidence and are not reported as screening results.
